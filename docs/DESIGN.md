# Кладовка — дизайн

Макеты всех экранов: **https://claude.ai/artifact/RCcKwh6HSQzCL4V1SnULCb** (канвас, часть экранов кликабельна).
Скриншоты собранного приложения — в [`docs/screens`](screens).

## Принципы

1. **Список уже собран.** Главный экран — не пустой список, а готовый заказ на ближайший день с суммой и
   количеством. Пользователь только проверяет.
2. **Одно главное действие на экране** — нативная `MainButton` Telegram: «Оформить заказ», «Заказ оформлен»,
   «Добавить в заказ».
3. **Деньги на виду.** Прогресс до бесплатной доставки и цена дозаказа показаны там, где принимается решение.
4. **5 секунд на «заканчивается».** Поиск с автофокусом, товары отсортированы по тому, что вероятнее кончится.
5. **Объясняем прогноз.** «Хватит до чт», «одной упаковки хватает на 30 дней — посчитали по покупкам»: без
   объяснения прогнозу не верят.
6. **Нативно для Telegram.** Цвета из темы пользователя, системная кнопка «назад», вибрация, без своего статус-бара.

## Экраны

| # | Экран | Что решает |
|---|---|---|
| 1 | Заказ | Дата ближайшего заказа, порог бесплатной доставки, предупреждение «не дотянет до заказа», «Нужно купить», «Проверьте наличие», «Можно взять впрок» |
| 2 | Что заканчивается? (шторка) | Быстро отметить товар; если не дотянет до заказа — выбор «подождёт / дозаказ / куплю сам» с ценой доставки |
| 3 | Ничего не забыли? | Вопросы о товарах без прогноза, проход по местам в доме, итог, копирование списка, сумма по чеку |
| 3б | Дозаказ | Всё, что кончится до планового заказа, + «заодно из заказа», чтобы не платить за доставку дважды |
| 4 | Запасы | Все товары с остатком в днях и полоской, фильтр «до заказа не хватит», поиск, кнопка «Заканчивается» |
| 5 | Карточка товара | Прогноз и его объяснение, «закончилось / мало / ещё много», цена, расход, «быстро портится», история |
| 6 | Траты | Месяц: потрачено, доставка, дозаказы, сэкономленное, список заказов |
| 7 | Настройка | День и частота заказа, доставка и порог; выбор товаров из каталога |

Навигация: сегментный переключатель «Заказ · Запасы · Траты» сверху (снизу место занимает `MainButton`),
вложенные экраны открываются стеком с нативной кнопкой «назад».

## Токены

Основные цвета приходят из `themeParams` Telegram; значения ниже — запасные (браузер) для светлой темы.

| Токен | Telegram | Запасной | Где |
|---|---|---|---|
| `--bg` | `secondary_bg_color` | `#EFEFF3` | фон экрана |
| `--surface` | `section_bg_color` | `#FFFFFF` | карточки, списки |
| `--text` | `text_color` | `#0F1419` | текст |
| `--hint` | `subtitle_text_color` / `hint_color` | `#5F6670` | подписи |
| `--accent` | `button_color` | `#1F78C1` | главная кнопка, прогресс, выбор |
| `--warn` / `--warn-bg` | — | `#B25400` / `#FFF1E0` | «не дотянет до заказа», дозаказ |
| `--out` | — | `#D93A31` | закончилось |
| `--ok` / `--ok-bg` | — | `#1F6B38` / `#E4F2E7` | экономия, «выгоднее» |

Категории различаются мягким фоном аватарки (продукты — зелёный, бытовая химия — синий, гигиена — фиолетовый,
питомцы — оранжевый). Для тёмной темы у всех статусных и категорийных цветов свои значения.

- Шрифт — **Onest** (хорошая кириллица), цифры моноширинные (`tabular-nums`), чтобы суммы не прыгали.
- Радиусы: карточки 16, кнопки 12–14, шторка 22.
- Касания ≥ 44 px; строка списка 64 px.
- Полоска запаса: синяя — хватит, оранжевая — не дотянет до заказа, красная — нет; штриховка — нет данных.
